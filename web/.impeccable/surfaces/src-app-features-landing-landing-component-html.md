# Landing (/) surface brief

Scope: landing. Mode: Persuade, with an academic audience (TFG/TFM tribunal plus dev/QA teams). Direction pinned by the user (not rolled): blueprint background, sober, no topo/glow/gradients/particles, palette polar white + glacier blue + racing red (focus only), Web-Interactions "touchable surface" and "transition as scroll". User rejected: giant hero type, a blueprint table as a component, cobalt/lime, notebook-paper grid.

## Direction contract

THESIS: The page is one drafting sheet. A verification is a technical drawing, so the whole site follows sheet conventions (frame, reference zones, title block, dimension lines, registration marks) and the cursor is a drafting instrument. Refuses: centred hero, giant display type, cards, a "diagram component", a plain notebook grid.
OWN-WORLD: Polar-white paper (#f5f8fb), ink #0b1620, deep glacier blue #1d4e76 for actions and rules, racing red #c8202f only for keyboard focus. Three line weights: 0.5px grid, 1px major grid with + marks, 1.5px sheet frame. Manrope for text, IBM Plex Mono for measurements. Rectangular 2px buttons, hairlines, no boxes.
STORY: Visitor understands in seconds that SVAES decides whether a release can ship and keeps the reason; sees what is delivered (10 rules, 20 connectors) versus what is research; believes it because every number on the sheet is a real count; acts via "Solicitar acceso".
FIRST VIEWPORT: Left: 44-48px statement on the grid baseline. Right-bottom: lead + one solid button. Fixed sheet frame with zone letters/numbers, a title block bottom-right (sheet name, zone, cursor position). Crosshair and a brighter local grid follow the pointer.
FORM: Drafting sheet with live cursor, position 1 of the user-pinned brief; seed: none (direction pinned by user, no roll).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
